# Agent 开发日记

由开发助手在每次实质改动完成后撰写一篇 `YYYY-MM-DD-主题.md`，不是每次运行都让
模型生成总结，也不是后台自动编写。机器记录见 [系统日志](../logging.md)。

每篇包括：

1. 日期、基线 commit、当前未提交改动/版本标识，用户目标与范围。
2. 这次实现/解决了什么，以及明确没有改变什么。
3. 实际验证：命令、真实模型或离线、结果路径、任务 ID 和主要指标。
4. 还存在哪些问题：区分已复现事实、推测、未验证事项。
5. 下一步建议及验证标准；没有复测就不宣称性能提升。

历史日记保留，后续结论变更另写一篇并引用原文，不把旧 baseline 覆盖成新结果。
日记可提交 Git；原始运行日志、评测数据和密钥不提交。
