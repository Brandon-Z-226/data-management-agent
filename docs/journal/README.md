# Agent 开发日记

按版本迭代记录：每个版本只有一篇日记，开发期间持续更新，版本确认完成后定稿。
不按日期、单次修复或运行新增日记，也不把中间修复拆成多个版本。
机器运行过程和精确评测证据保存在 [系统日志](../logging.md)，不混入版本叙述。

文件名使用 `vN-english-summary.md`，例如
`v1-dynamic-plan-act-verify.md`；标题使用 `vN - 版本概述`。
正文开头记录日期。以项目作者的口吻直接描述工作，不写对话回复或任务交接报告。

内容重点：

1. 上一版本遇到了什么问题，这一版本要解决什么。
2. 改了什么策略，增加或调整了什么模块、功能，为什么这样做。
3. 验证后解决了什么、效果如何；明确区分离线测试和真实模型结果。
4. 仍有哪些问题、限制或取舍，下一版本准备关注什么。

不写“按照用户要求”“助手完成”等叙述，不记录 commit、push 等琐事，
无需精确到代码文件或函数名。只保留必要结果摘要，不复制敏感内容。
没有验证就不宣称效果改善；历史 baseline 不覆盖为新结果。
